## Какой файл скачать

На странице версии в разделе **Assets** лежат несколько файлов:

| Файл заканчивается на | Для каких телефонов |
|---|---|
| ⭐ **`arm64-v8a.apk`** | Почти все телефоны с 2017 года. **Начните с него** |
| `armeabi-v7a.apk` | Старые и бюджетные телефоны |
| `universal.apk` | Любой телефон, если не уверены (файл больше) |
| `x86_64.apk` | Эмуляторы и Chromebook |

## Что умеет

- 🔐 **VLESS + Reality** с обходом DPI: фрагментация TLS, как в Xray
- 📋 **Подписки 3x-ui и Marzban**: обновляются сами, показывают трафик и срок, напоминают о продлении
- 🧭 **Три режима**: всё через VPN · российские сайты напрямую · только заблокированные сайты
- ⚡ **Автовыбор** самого быстрого сервера и реальная задержка через туннель
- 📱 **Выбор приложений**, которые идут через VPN
- 🔔 **Живое уведомление**: скорость, задержка, текущий сервер и кнопка «Отключить»
- 🧩 **Плитка в шторке** и автоподключение при включении телефона
- 🔄 **Обновления прямо из приложения**

## Как установить

1. Скачайте APK на телефон и откройте его.
2. Если Android спросит, разрешите установку из браузера или файлового менеджера.
3. В Kivin нажмите **«Добавить»** и вставьте адрес подписки или ссылку `vless://`.
4. Нажмите кнопку подключения и подтвердите запрос Android на VPN.

Дальше обновляться вручную не нужно: Kivin сам покажет карточку «Доступна версия» с кнопкой «Обновить».
