## 🚀 Как установить

### 📱 Android

1. Скачайте APK на телефон и откройте его.
2. Если Android спросит, разрешите установку из браузера или файлового менеджера.
3. В Kivin нажмите **«Добавить»** и вставьте адрес подписки или ссылку `vless://`.
4. Нажмите кнопку подключения и подтвердите запрос Android на VPN.

Дальше обновляться вручную не нужно: Kivin сам покажет карточку «Доступна версия» с кнопкой «Обновить».

### 💻 Windows

1. Скачайте архив `windows-x64.zip` и распакуйте его в любую папку, например `C:\Kivin`.
2. Запустите **`Kivin.exe`** и разрешите изменения: права администратора нужны для VPN-адаптера.
3. Если появится «Система Windows защитила ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. Нажмите **«+»** и вставьте адрес подписки, затем кнопку подключения.

> [!NOTE]
> Перед подключением выключите другой VPN-клиент, если он запущен. Новые версии для Windows пока скачиваются вручную с этой страницы.
